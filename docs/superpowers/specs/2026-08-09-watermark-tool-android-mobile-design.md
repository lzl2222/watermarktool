# 去水印工具 · Android 手机版 设计文档

- 日期：2026-08-09
- 状态：已确认（用户认可方案 A：Kivy + GitHub Actions 云端编译 APK）
- 设计系统来源：ui-ux-pro-max skill（Liquid Glass 液态玻璃风格）

---

## 1. 产品定位

手机本地运行的去水印下载器（豆包 / 小红书 / 抖音）。
用户粘贴分享链接 → 自动识别平台 → 解析无水印资源 → 选择下载 → 保存到手机相册/下载目录。
**全程本地运行，不依赖任何服务器**（GitHub Actions 仅在编译 APK 时使用一次）。

## 2. 设计系统（ui-ux-pro-max 规范）

### 2.1 风格
- **Liquid Glass（液态玻璃）**：浅色/深色双模式完整支持
- 毛玻璃质感：半透明面板（rgba 白 10~30%）叠在**高饱和渐变背景**上，模拟模糊玻璃
- 1px 细描边（rgba 白 0.08~0.2）+ 大圆角（16~24dp）+ 悬浮层次感

### 2.2 配色（两套主题）

**深色模式（默认，OLED 友好）**

|---|---|
| 背景 | #0F172A（深空蓝黑） |
| 主色（品牌/高亮） | #EC4899 视频粉 |
| 强调色（主操作按钮） | #2563EB 时序蓝 |

### 2.3 字体
- 数字/英文：Roboto / Inter（Android 系统默认）
- 中文：系统默认（Noto Sans CJK）
- 标题 20sp 粗体；正文 15sp；辅助 12sp；行高 ≥1.4

### 2.4 图标规范（重要）
- **禁用 emoji 当图标**（Android 上同样会渲染异常/显廉价）
- 所有图标用 **PIL/Kivy 绘制的矢量风格图标**（播放、暂停、下载、历史、主题、链接、图片、视频、动图、勾选、删除）
- 图标统一 24dp 描边风格，颜色跟随主题

### 2.5 圆角 / 间距 / 触摸规范
- 面板圆角 20dp；按钮圆角 16dp；输入框圆角 14dp；卡片圆角 16dp
- 页面边距 16dp；组件间距 12dp；卡片间距 10dp
- **所有可点击目标 >= 48x48dp**（Kivy 触摸优化）
- 内容区域底部预留安全区（手势条/导航条）

## 3. 界面规范（逐屏）

### 3.1 主屏（空状态）
- 顶部渐变玻璃条：PIL 生成渐变图铺满，毛玻璃感，标题「去水印」+ 主题切换
- 平台徽章（解析后显示）
- 大输入框（多行，圆角玻璃）+ 「解析」强调色大按钮 >=48dp
- 状态文字（次要色）
- 空状态提示（居中，淡入动画）
- 历史记录（最近3条）轻量入口

### 3.2 解析中（Loading 动画）
- 输入框上方出现玻璃加载卡片，内含**旋转流光圆环**（Kivy Animation 旋转 800ms 循环）+ 文字「正在解析 小红书 链接…」
- 解析按钮变为禁用态（透明度 0.6）
- 超过 15s 显示「解析较慢，请稍候…」（不卡死，可取消）
- 完成 → 圆环消失 + 结果卡片淡入+上移 200ms

### 3.3 结果：视频笔记
- [平台徽章] [无水印] 彩色胶囊徽章
- 视频预览用 Kivy VideoPlayer（系统解码，流畅），封面+点击播放
- 作者 · 分辨率 · 时长（次要文字）
- 标题/描述（2行截断）
- 「下载视频（无水印）」强调色大按钮，点击后按钮内出现微型进度动画

### 3.4 结果：图文 / 动图笔记
- 类型汇总「图 8 · 动图 2」+ [全选]/[取消全选] 幽灵按钮
- 3列网格（自适应屏宽），RecycleView 虚拟滚动
- 每卡片：圆角玻璃卡片 + 右下角圆形勾选框（选中=强调色填充+白色对勾，带动画）
- 动图卡片角标「动图」；视频封面角标「视频」
- 底部固定「下载所选 (N)」大按钮，N 实时更新

### 3.5 下载进度（高级动画）
- 下载按钮变为**进度胶囊**：背景填充色 0→100% 平滑推进（400ms/档）
- 中央显示百分比 + 当前文件名
- 完成 → 胶囊变绿 + 对勾弹跳（scale 1→1.15→1，250ms）→「已保存到相册」
- 失败 → 胶囊变红 + 抖动（±6px，3次，200ms）+ 错误弹窗
- 多文件：显示 `3/10` + 总进度条

### 3.6 历史记录
- 底部轻量抽屉（上滑打开 300ms）
- 每条：平台 + 标题 + 时间 + 类型 + 重新解析
- 存储：本地 SQLite（history.db），最多 50 条

### 3.7 主题切换
- 右上角「深色/浅色」胶囊按钮，颜色过渡动画 300ms，持久化到本地配置

## 4. 动效规范汇总（ui-ux-pro-max motion 规范）

| 交互 | 动画 | 时长 | 缓动 |
|---|---|---|---|
| 按钮按下 | 缩放 0.97 + 亮度变化 | 150ms | out_quad |
| 卡片出现 | 淡入 + 上移 8dp | 250ms | out_cubic |
| 网格卡片 | 逐张淡入（30ms 间隔） | 300-450ms | out_back |
| 解析 Loading | 旋转流光圆环循环 | 800ms loop | linear |
| 页面切换（空→结果） | 内容区淡入 + 上移 | 200-300ms | in_out_cubic |
| 下载进度 | 填充推进 | 400ms/档 | out_quad |
| 下载完成 | 对勾弹跳 | 250ms | out_back |
| 下载失败 | 抖动 | 200msx3 | linear |
| 主题切换 | 颜色过渡 | 300ms | in_out_cubic |
| 历史抽屉 | 上滑 | 300ms | in_out_cubic |

原则：流畅优先，动画 <=600ms，尊重系统「减少动态效果」设置。

## 5. 功能与数据流

粘贴文本 → extract_url 提取链接 → detect 平台
  → doubao_parser / xiaohongshu_parser / douyin_parser .parse()
  → 统一 meta dict → 渲染结果卡片/网格 → 用户勾选 → 逐项下载（进度）
  → 保存到 MediaStore（相册/下载目录）→ 完成提示

- 解析器 = 桌面版 4 个模块原样复用（已确认纯 Python 可移植）
- 下载 = requests 流式分块 + Content-Type 修正扩展名 + 403/404 回退（与桌面版一致）
- 保存：Android 9+ 用 MediaStore（相册可见）；Android 8- 用公共下载目录 + WRITE_EXTERNAL_STORAGE
- 图片格式：原图经 sns-img-bd 高清化（PNG/JPG 按实际 Content-Type）

## 6. 错误处理

| 场景 | 表现 |
|---|---|
| 无 token / 笔记 404 | 红色胶囊提示「链接缺少访问凭证，请从 App 重新复制」 |
| 触发风控 | 「解析频繁，请稍后再试」+ 2s 后恢复 |
| 网络失败 | 重试 3 次（退避 0.5s），仍失败给错误弹窗 |
| 下载失败 | 抖动动画 + 弹窗 + 保留重试按钮 |
| 无内容类型 | 「该笔记需要登录查看」 |

## 7. 性能与流畅度

- RecycleView 虚拟滚动（长列表不卡）
- 缩略图并发 <=4（信号量）+ 磁盘缓存
- 解析/下载全部在后台线程，UI 线程只做渲染
- 启动即用：不加载桌面版无关依赖（去掉 customtkinter/tkinter/ffmpeg）
- 下载大文件用流式 + 断点续传（Range 头）

## 8. 测试方案

1. 核心逻辑（本机可测）：解析器在 Python 3 下跑通 3 平台（联网测试）
2. Kivy UI（本机可测）：Windows 上安装 Kivy 跑同一套 UI 代码（Kivy 跨平台），验证布局/动画/流程
3. APK 构建：GitHub Actions 自动编译（arm64-v8a，适配小米）
4. 真机清单（用户拿到 APK 后）：安装、粘贴链接、3平台解析、图文/动图/视频下载、相册可见、深/浅主题、断网提示

## 9. 构建与交付（小米手机安装）

- mobile/buildozer.spec：包名 org.watermark.tool，架构 arm64-v8a，权限（网络、MediaStore）
- .github/workflows/build-android.yml：push → ubuntu 构建 → 上传 APK artifact
- 交付物：mobile/ 源码 + buildozer.spec + GitHub Actions + README-安卓版.md 傻瓜教程
- 小米安装：下载 APK → 打开（允许「未知来源」）→ 安装；HyperOS 下 App 前台运行不受后台限制

## 10. 范围外（明确不做）

- 不做本地 FFmpeg 去水印（手机直链即无水印）
- 不做自动更新（用户重新下载新 APK 即可）
- 不做后台常驻/推送
